# On-Prem Virtual Infrastructure Lab

## Objective
Build a virtualized lab environment to simulate cloud infrastructure.

## Environment
- Hyper-V
- Windows Server 2019 (Management)
- Fedora Server (CLI only)

## Hardware
- Intel i5-7500
- 48GB RAM
- 500GB SSD (Host OS)
- 1TB SSD (VM storage)
- 2x 4TB HDD
