## Overview

This lab environment is running on a local server using Hyper-V as a hypervisor.

## Components

- Host Machine:
  - Windows (Hyper-V enabled)

- Virtual Machine:
  - Fedora Server
  - Used for Linux administration and cloud fundamentals practice

## Networking

- VM is connected to local network
- Uses static IP address
- Accessible via SSH

## Security

- SSH key-based authentication enabled
- Password login disabled
