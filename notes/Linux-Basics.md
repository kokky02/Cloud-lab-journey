## Linux Basics

### Kernel
Kernel is the core of the operating system. It manages CPU, memory, hardware communication and system processes.

### Root user
Root is the superuser with UID 0 and full system privileges.

### Swap
Swap is disk space used as virtual memory when RAM is exhausted.

### Filesystem
Fedora Server uses XFS as the main filesystem for performance and scalability.
